### 🛒 MERN E-Commerce Website

A full-stack e-commerce web application built using the MERN stack. The application provides a complete online shopping experience with secure authentication, product management, shopping cart, order processing, payment integration, user reviews, and an admin dashboard.

---

### 👤 User Features

* User Registration & Login
* JWT Authentication & Authorization
* Forgot Password & Reset Password
* Update Profile & Change Password
* Browse Products
* Search Products
* Filter by Category

* Product Details Page

* Shopping Cart
* Shipping Information
* Order Placement

* Remove Items from Cart
* Product Stock Validation

* Admin Dashboard
* Manage Products

* Manage Orders
* Update Order Status
* Manage Users

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/tasnim-zeba/E-commerce-website.git
```

### Navigate to the project

```bash
 cd E-commerce-website
```

### Install Backend Dependencies

```bash
cd backend
npm install
```

### Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

---

## ▶️ Running the Application

### Start Backend

```bash
cd backend
npm run dev
```

### Start Frontend

```bash
cd frontend
npm start
```

The frontend runs on:

```
http://localhost:3000
```

The backend runs on:

```
http://localhost:4000
```

---

## 🔑 Environment Variables

Create a `config.env` file inside the backend configuration directory and configure the following variables:

```env
PORT=
FRONTEND_PORT=
DB_URI = 
JWT_SECRET = 
JWT_EXPIRE = 
COOKIE_EXPIRE = 
SMPT_SERVICE = 
SMPT_MAIL = 
SMPT_PASSWORD = 
SMPT_HOST = 
SMPT_PORT = 
CLOUDINARY_NAME = 
CLOUDINARY_API_KEY = 
CLOUDINARY_API_SECRET = 
```
